# TETRIS

A minimal black & white Tetris in plain HTML/JS — no dependencies.

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move |
| ↑ | Rotate |
| ↓ | Soft drop |
| Space | Hard drop |
| P | Pause |

## Run locally

Open `index.html` in any browser, or:

```bash
python -m http.server
# → http://localhost:8000
```
